# タレントマネジメントシステム（カルテ）PoC - MVP選定

## 1. MVPの基本方針

### 目的

- 「カルテ」がエンジニアのスキル・経験を可視化できるかを検証する。
- 生成AIがどこで有効かを試験的に導入・評価する。

### MVPの優先基準

✅ 最小限の実装で価値がある  
✅ エンジニアのデータ管理・検索ができる  
✅ 生成AIの導入ポイントを試せる

## 2. MVPに含める機能

### 🔹 必須機能

- **エンジニア情報管理**: 基本情報の登録・表示（名前、職種、所属、スキル、プロジェクト履歴）
- **スキル登録・管理**: スキルを蓄積・可視化（スキル名、カテゴリ、レベル）
- **スキル検索**: 必要なスキルを持つエンジニアを検索（フィルタ機能）
- **生成AIによるスキル推薦**: 生成AI活用の検証（関連スキルの提案）
- **シンプルなUI**: 直感的に使えるインターフェース（エンジニアリスト・詳細ページ）

### 🔹 削減する機能（MVP以降に検討）

- **プロジェクト履歴の詳細管理**: 最小限の実装では不要
- **評価機能（360度評価）**: PoC段階では優先度低
- **キャリアプラン作成**: 運用フェーズで評価すべき

## 3. MVPの開発ステップ

1️⃣ **データモデル実装**

- SQLiteを使って、シンプルなエンジニア・スキル管理DBを作成

2️⃣ **バックエンドAPI開発**

- FastAPI（またはASP.NET Core）を用いて、基本的なCRUD APIを構築

3️⃣ **フロントエンド開発**

- React（Next.js）でエンジニア一覧・詳細表示・検索機能を実装

4️⃣ **生成AIの試験導入**

- スキル推薦機能のため、OpenAI API / Azure OpenAI を利用

5️⃣ **PoCテスト & フィードバック**

- 使いやすさ・データの正確性・生成AIの有用性を評価

## 4. MVP選定の結論

✅ **「エンジニアのスキル・経験を可視化し、検索・推薦できるシステム」**  
✅ **生成AIを活用したスキル推薦機能を試験導入**

この方向でPoCを進める。次のステップとして、詳細なタスク分解を行い、開発計画を策定する。
