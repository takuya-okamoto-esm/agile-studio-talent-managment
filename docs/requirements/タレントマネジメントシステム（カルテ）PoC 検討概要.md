# タレントマネジメントシステム（カルテ）PoC 検討概要

## 1. 背景と目的

### 導入の背景
- 受託開発を行うソフトウェア開発部門でエンジニアのスキル・経験を可視化する。
- 既存の全社システムとの連携は計画しておらず、部門内での運用を前提とする。

### 導入の目的
1. エンジニアのスキル・経験を蓄積し、組織内でフラットに可視化。
2. 育成のためのスキル教育に必要なヒントを得る。
3. 顧客の要望に応じて適切なスキル保有者を提案。
4. 生成AIを活用し、システム開発への貢献を検証。
5. 生成AIの活用方法の最適解を探る。

## 2. PoC開発方針
- システムがエンジニアのスキル・経験を蓄積し可視化できるか検証。
- 生成AIの導入効果を評価し、適用領域を検討。

## 3. PoCで実装する基本機能
- **エンジニア情報の登録・管理**（名前、職種、所属、スキル）
- **スキル可視化**（スキルマップ表示、検索機能）
- **プロジェクト履歴管理**（期間、利用技術、役割）
- **生成AIを活用したスキル推薦、自動ドキュメント生成**

## 4. 生成AIの活用ポイント
- スキル・プロジェクトの自動分類、推薦の効果検証。
- コード生成・補完による開発スピード向上の実証。
- 自動ドキュメント作成の有用性評価。
- 問い合わせ対応やナレッジベース生成の自動化。

## 5. 次のステップ
- **データモデルと権限設計の詳細化**
- **スキル検索機能の設計**
- **生成AIの活用シナリオを試験実装**

このPoCを進め、開発スケジュールを策定し、実装を開始。
